# Simple Bill Calculator

## Description

This is a simple Python program that calculates the total cost of items based on their price and quantity.

## How It Works

The program:

1. Asks the user to enter the price of one item.
2. Asks the user to enter the quantity.
3. Converts the price to a float and the quantity to an integer.
4. Calculates the total.
5. Displays the result using an f-string.

## Example

```text
Enter the price of one item: 50
Enter the quantity: 3

3 items at 50.00 each = 150.00
```
